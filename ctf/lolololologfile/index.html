1. 이미지 파일 분석

FTK Imager로 이미지 파일을 열면 [root] 영역에서 삭제된 파일을 발견할 수 있다.

1-1. unallocated space

  • 삭제된 파일의 데이터가 남아 있을 수 있는 영역이다.

1-2. 파일 추출

  1. unallocated space에서 삭제된 파일들과 동일한 크기를 갖는 파일이 존재하는 것을 확인한다.
  2. 해당 파일들을 export한다.

2. 로그 파일 분석

추출한 파일을 HxD로 열어 내용을 확인한다.

3. FLAG

도구의 파일 연결 기능을 사용해 파일을 하나로 합친다.
